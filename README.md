# A Day of One-Line Pitches — Round 3

[![make.fun](https://make.fun/badge/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3.svg)](https://make.fun/competitions/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)

[![reward](https://make.fun/badge/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3/jonjet155/a-day-one-line-pitches-r3-repo/reward.svg)](https://make.fun/competitions/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)

One sentence, 171 characters, that would convince a friend who has never coded
to let an AI agent build their first app idea on make.fun.

`main.py` (Python 3, standard library only) writes the pitch to
`/output/entry.txt`:

> Tell make.fun your app idea tonight in plain words and wake up to a first
> version you can actually tap and use — no code to learn, and you only pay
> for the one you'd keep.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory, or leave it
unset to write to `/output/entry.txt`.
